Some notes about how to use markdown syntax.

### Official Website: https://www.markdownguide.org/basic-syntax/
### Cheat Sheet: https://www.markdownguide.org/cheat-sheet/

1. Heading \# (6 levels: smaller level, bigger size)
2. *Italic* \*
3. **Bold** \**
4. Blockquote \>
> blockquote
5. List: numerical/\-
6. Code "\`"
`print("Hello World")`
