# MarkdownNote
Some notes about how to use markdown syntax.

[Official Website](https://www.markdownguide.org/basic-syntax/)
[Cheat Sheet](https://www.markdownguide.org/cheat-sheet/)

Backslash \: To show the reserved character up under the markdown mode.

#### Size
Heading \# (6 levels: smaller level, bigger size)

#### Font
1. *Italic* \*
2. **Bold** \**
3. ==Highlight== \==
4. ~~Strikethrough~~ \~~

#### Format
1. Blockquote \>
> blockquote
2. Horizontal Rule \--- or \***
---
***
3. List: numerical/\-
4. Task List \- \[ \]
   - [x] Add x between [] to select a checkbox.
   - [] Something haven't done yet...

#### Code "\`"
`print("Hello World")`

#### Hyperlink
1. Link \[title](link)
[My GitHub Profile](https://github.com/shantinghsu)
